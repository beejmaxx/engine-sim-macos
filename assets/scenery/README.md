# Pine-grove scenery

`pine-grove.png` is the unmodified transparent preview render of Poly Haven's
**Pine Tree 01**, by **Rico Cilliers (modeling)** and **Rob Tuytel (photography)**.
Poly Haven assets are dedicated to the public domain under **CC0 1.0**.

- [Source asset and credits](https://polyhaven.com/a/pine_tree_01)
- [Downloaded 1024-pixel preview](https://cdn.polyhaven.com/asset_img/thumbs/pine_tree_01.png?width=1024&height=1024)
- [Poly Haven license](https://polyhaven.com/license)
- [CC0 legal text](CC0-1.0.txt)

The renderer places this image on camera-facing vertical planes, with mipmaps,
alpha masking, varied placement/size/tint and distance fog. It does not include
the full 3D tree model. The texture ships with the app; there is no runtime
network dependency.
